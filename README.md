# smart_gift_finder

Smart Gift Finder — AI-powered app that recommends the perfect gift based on the recipient's interests, age, and budget.

## Getting Started

```sh
flutter pub get
flutter create .      # regenerates android/ios/web/... (platform folders are gitignored)
flutter run
```
